# 📈 FinLearn — Investment & Finance Mastery

A **production-grade financial education platform** teaching stocks, bonds, mutual funds, options, and investment strategies. Built with vanilla JavaScript, responsive design, and professional aesthetic.

## ✨ What's Included

🎓 **15+ Comprehensive Lessons**
- What Are Stocks? (with Apple AAPL real data)
- Understanding Bonds (types, yields, pricing)
- Mutual Funds & ETFs (comparison with cost impact)
- Building Portfolios (age-based models)
- Advanced topics (options, technical analysis, behavioral finance)

🧮 **4 Interactive Calculators**
- Compound Interest (see $1M+ growth potential)
- Stock Profit/Loss (includes commissions, ROI)
- Dividend Income (annual + monthly projections)
- Portfolio Simulator (test allocations, 30-year outlook)

📚 **20+ Glossary Terms**
- Clear definitions with real-world examples
- Searchable interface
- Investment terminology demystified

📱 **100% Mobile Responsive**
- Perfect on phones, tablets, desktops
- Touch-optimized buttons (48px)
- Auto-collapsing sidebar
- Zero horizontal scroll

⚡ **Ultra-Fast & Lightweight**
- 57KB total (HTML + CSS + JS)
- No dependencies (vanilla JS only)
- Loads in <1 second
- Client-side only (no backend)
