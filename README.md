# Investment & Finance Trainer

A comprehensive, interactive platform for learning stocks, bonds, options, mutual funds, and investment strategies. Built for mobile-first learning with real examples, visualizations, and interactive tools.

## Features
- Complete financial education curriculum
- Interactive portfolio simulator
- Real-world investment examples
- Glossary with visual definitions
- Investment calculators
- Risk/reward analysis tools
- Mobile-responsive design

## Tech Stack
- Vanilla HTML5, CSS3, JavaScript
- No dependencies (pure frontend)
- GitHub Pages deployment

## Author
